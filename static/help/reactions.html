Reactions answers two questions: what is worth reacting right now, and how to lay that work across your characters' reactors so it is as few logins and as few numbers to type as possible. It runs standalone — you do not need the Manufacturing tab to use it.

1. Tell it your rhythm

Come back every N days is the setting the whole plan is shaped around. It is a duration, not a calendar — no weekday, no time of day. Every job is planned to fit inside that window so one login collects a whole stage. It is a target, not an absolute: where a stage genuinely cannot fit, the plan says so on the row rather than quietly running long.

2. Ask what is worth doing

The suggestion wizard ranks opportunities by profit against what you can actually run — your formulas, your reactors, your budget. Profit is quoted at buy orders, what you would really get selling into the book today, never at optimistic sell-order prices. Sell-side figures are still shown, labelled as what they are.

3. Assign it

Assigning lays the work out across characters: every job of a product carries the same run count so there is one number to read and type, free reactors get used rather than sitting idle, and a stage's jobs land together. Where the layout spends a little extra goo to achieve that, it tells you how much and what dropping to per-product counts would recover.

4. Run it

The dashboard shows what is running, what is ready to install next, and what is waiting on a stage below it. A chain's stages run in order — stage 2 cannot start before stage 1 finishes, because the game needs the materials to exist at install time.

What it deliberately leaves to you

Whether to run or sell, how much risk to take, and corp politics. Everything the tool can work out for itself — your reaction speed from your own finished jobs, where jobs are installed, how deep a chain is worth searching — it works out rather than asking.
